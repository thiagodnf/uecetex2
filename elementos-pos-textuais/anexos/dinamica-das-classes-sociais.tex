\anexo{Dinâmica das classes sociais}

Este arquivo ilustra como fica um anexo já preenchido: um documento produzido por terceiros (por exemplo, um infográfico ou relatório de um órgão como o IPECE), incluído aqui apenas como fundamentação para uma afirmação feita no corpo do trabalho -- não escrito pelo autor do TCC. Substitua pelo(s) anexo(s) real(is) do seu trabalho (uma norma, um relatório institucional, um documento oficial etc.), sempre indicando a fonte de onde o documento foi obtido.

Fonte: IPECE (2008).
